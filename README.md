## NimbusPay Ticket Triage — VIMA3YA ML Intern Assessment

Compact project package for auditing support-ticket labels, running prompt baselines, fine-tuning an instruction model with QLoRA, evaluating on the development set, running controlled experiments, analyzing errors, and generating the required test predictions.

### Files
- `notebook.ipynb` — end-to-end Google Colab workflow (recommended runtime: NVIDIA T4 GPU).
- `SCHEMA.md` — output schema and business rules copied from the assessment specification.
- `score.py` — supplied scoring utility.
- `cleaning_log.csv` — data-cleaning actions from the local audit of the supplied training data.
- `report.md` — assessment report; update it with measured Colab results before submission.
- `LOCAL_CHECKS.txt` — local, CPU-side validation status.
- `.gitignore` — excludes assessment inputs, generated predictions, adapters and runtime outputs.

### Run
1. Download the original `training_assessment.zip` from the assessment materials. **It is intentionally not committed to this repository.**
2. Open `notebook.ipynb` in Google Colab and select Runtime → Change runtime type → T4 GPU.
3. Run the notebook from the top. When prompted, upload the original `training_assessment.zip` from your local machine.
4. Review the cleaning report and baseline results, then run the training, experiment, dev evaluation and test-inference sections.
5. Download the generated submission bundle and verify all required files before submitting.

### Important status disclosure
The repository contains the project code, notebook and audited cleaning log. CPU-side data validation was completed locally (1,445 input train rows; 1,420 retained; 25 malformed rows dropped; 157 unique rows repaired; 182 cleaning-log actions). GPU fine-tuning, baseline scores, controlled experiment results, final adapter and 400 test predictions must be generated by executing the notebook on Colab. No model accuracy or final predictions are claimed in advance.
