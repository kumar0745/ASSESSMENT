## NimbusPay Ticket Triage — VIMA3YA ML Intern Assessment

A compact project for auditing customer-support labels, running prompt baselines, fine-tuning an instruction model with QLoRA, evaluating the development set, comparing controlled experiments, analyzing errors and generating test predictions.

### Repository files
- `notebook.ipynb.gz` — compressed complete Google Colab notebook.
- `extract_notebook.py` — decompresses the notebook into `notebook.ipynb`.
- `SCHEMA.md` — assessment output schema and business rules.
- `score.py` — assessment scoring utility.
- `cleaning_log.csv` — data-cleaning actions from the local training-data audit.
- `report.md` — report template; replace placeholders with measured Colab results.
- `LOCAL_CHECKS.txt` — CPU-side validation summary.
- `.gitignore` — excludes assessment inputs and generated outputs.

### Run the notebook
1. Clone or download this private repository.
2. Extract the notebook file:
   ```bash
   python extract_notebook.py
   ```
   This creates `notebook.ipynb` from `notebook.ipynb.gz`.
3. Upload `notebook.ipynb` to Google Colab and select Runtime → Change runtime type → T4 GPU.
4. Download the original `training_assessment.zip` from the assessment materials. **It is intentionally not committed to this repository.**
5. Run the notebook from the top. When prompted, upload the original `training_assessment.zip`.
6. Review the data audit, baseline results, training logs and four controlled experiment results.
7. Run dev evaluation/error analysis and generate all 400 test predictions.
8. Download and inspect the generated submission bundle before submitting.
